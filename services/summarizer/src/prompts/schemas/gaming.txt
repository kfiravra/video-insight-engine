<domain_schema name="gaming">
GAMING DATA — GamingData schema

Extract structured gaming / gameplay / playthrough content.

THINKING GUIDE:
- Gaming content shows someone PLAYING — the value is the highlights worth
  re-watching, the build/loadout worth copying, the route worth following,
  and the rankings the creator argues for.
- Highlights are the moments that matter: clutch plays, big fails, boss kills,
  turning points. Set a timestamp on each so the viewer can jump.
- The loadout is the gear / perks / settings / build the creator runs — a
  checklist the viewer can replicate.
- The walkthrough is the ordered route through a level / quest / match.
- Rankings are the creator's tier opinions (characters, weapons, maps, agents).
  This is the gaming signature — surface the ranking as a draggable tier list.

{
  "title": "The game / video focus in one line, or null",
  "highlights": [
    {
      "label": "What happens at this moment",
      "description": "1 sentence of detail",
      "timestamp": 0
    }
  ],
> UI: highlights → MomentTrack. Set timestamp (seconds) so viewers jump to each play.
  "loadout": [
    {
      "item": "Weapon, perk, gear, or setting",
      "category": "Optional grouping (weapons, perks, settings)",
      "note": "Why it's picked, short"
    }
  ],
> UI: loadout → Checklist. The viewer ticks off what they've copied.
  "walkthrough": [
    {
      "instruction": "What to do at this stage",
      "timestamp": 0
    }
  ],
> UI: walkthrough → StepFlowCanvas. Ordered route stages, in play order.
  "rankings": [
    {
      "item": "Thing being ranked (character, weapon, map)",
      "tier": "S | A | B | C | D",
      "reason": "Why it sits in that tier, short",
      "emoji": "relevant emoji"
    }
  ]
> UI: rankings → TierList. tier is the creator's SUGGESTED placement (the viewer can override + reorder). Use only S/A/B/C/D. When the creator gives no tier, omit it — the viewer places it.
> UNBOXING / box-break videos: rankings = the PULLED items — card/product name as item, rarity or market-value bracket as tier (chase/alt-art = S, SR/strong = A, playable = B, filler = C/D), and WHY it matters (rarity, price, playability, the creator's reaction) as reason. highlights = the pull MOMENTS with timestamps so viewers can jump to each reveal.
}

RULES:
- A ranking's tier MUST be one of: S, A, B, C, D (uppercase). Omit when the
  creator does not state one — never invent a tier.
- Preserve exact stats, sensitivities, and version numbers; do not round.
- highlights timestamps must be ascending, in seconds.
- One item per ranking row — do not collapse two characters into one row.

COMMON MISTAKES:
- Putting everything in S tier — a tier list that doesn't discriminate is useless.
- Treating the walkthrough as unordered tips — it is a sequence.
- Mixing loadout (what to equip) with walkthrough (what to do) — keep them apart.
