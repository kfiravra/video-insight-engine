<domain_schema name="learning">
LEARNING DATA — LearningData schema

Extract structured educational content.

{
  "keyPoints": [
    {
      "emoji": "single emoji matching the topic",
      "title": "Clear, specific title (not 'Important Point' but 'Redis Caching Reduces DB Load by 90%')",
      "detail": "2-3 sentences with specific details — numbers, names, quotes, examples from the video",
      "timestamp": null
    }
  ],
  "keyIdeas": [
    {
      "claim": "The idea as the speaker argues it — one full sentence a reader could disagree with",
      "why": "The speaker's reasoning or evidence for it, 1-2 sentences with the names and numbers used",
      "quote": "The speaker's own words that carry the claim, verbatim, at most 25 words — or null",
      "timestamp": null,
      "section": "Short name of the part of the video the idea belongs to",
      "kind": "thesis | argument | announcement | number | story | ask"
    }
  ],
> UI: Key ideas → spot cards (claim, why, quote, seek chip) grouped by section; the kind is the card's badge, and stamped figures also feed the answer tab's numbers strip.
> KEY IDEAS: for a talk, lecture or podcast — what the speaker wants you to believe or do. One distinct claim per item, never two merged; `timestamp` = the second the claim is said; `quote` = the exact words, never a paraphrase; `kind`: thesis (the video's central claim), argument, announcement, number (a figure used as evidence), story (an anecdote that carries a point), ask (what the speaker asks the audience to do). keyPoints stays for an explainer that teaches facts.
  "concepts": [
    {
      "name": "Term as the speaker uses it",
      "emoji": "relevant emoji",
      "definition": "Speaker's explanation, not a textbook definition",
      "example": "Example from the video or null",
      "analogy": "Analogy from the video or null",
      "group": "Short thematic group this concept belongs to (e.g. Foundations / Mechanics / Applications)",
      "connections": [
        {"to": "EXACT name of another concept", "type": "causes | requires | contrasts | partOf | relatesTo"}
      ]
    }
  ],
> UI: Concepts → ConceptCanvas tiered graph explorer (grouped lanes + typed edges) when connections are populated; otherwise falls back to FlashDeck flip cards.
> CONNECTIONS: list the 0-3 `connections` the speaker draws from each concept to other concepts in this same `concepts` array. Each connection is an object: `to` is the EXACT NAME of the other concept, `type` is the relationship the speaker draws — `causes`/`requires` (X drives or depends on Y), `contrasts` (X is opposed to / a trade-off against Y), `partOf` (X is a component of Y), or `relatesTo` (loose association). Never invent a link to fill the canvas: when the speaker draws none for a concept, leave its array empty.
> GROUPING: assign every concept a short `group` label — aim for 2-5 thematic groups across the whole list (e.g. Foundations / Mechanics / Applications). When the video is richer, group tightly rather than listing more disconnected terms.
  "takeaways": [
    "Actionable conclusion starting with a verb: Use..., Implement..., Avoid..."
  ],
  "timestamps": [
    {
      "time": "M:SS or H:MM:SS",
      "seconds": 0,
      "label": "Descriptive label for this moment"
    }
  ],
> UI: Timestamps → MomentTrack items (navigation points — no endSeconds). Fill seconds for playback jump links.
  "keyQuestion": "Central question this video answers",
  "summary": "2-3 sentence summary of the core teaching"
}

{
  "keyPoints": [
    {"emoji": "🧠", "title": "Compound interest works both ways", "detail": "Not just savings — debt compounds too. A $5,000 credit card balance at 24% APR becomes $6,200 in one year without payments.", "timestamp": 145}
  ],
  "keyIdeas": [
    {"claim": "Paying off high-interest debt beats investing the same dollar", "why": "A 24% APR balance costs more each year than the 7% a typical index fund returns, so the payoff is a guaranteed 24% return.", "quote": "Every dollar on that card is losing you twenty-four cents a year.", "timestamp": 312, "section": "Debt first", "kind": "argument"}
  ],
  "concepts": [
    {"name": "Time value of money", "emoji": "💵", "definition": "A dollar today is worth more than a dollar tomorrow because you can invest it. The speaker uses the example: '$100 invested at 7% doubles in ~10 years.'", "example": "$100 invested at 7% doubles in ~10 years", "analogy": null, "group": "Foundations", "connections": [{"to": "Compound interest", "type": "causes"}]}
  ]
}

COMPLETENESS:
- Cover the full video chronologically — don't cluster points from the first 10 minutes

RULES:
- keyPoints teach one specific thing each — no filler
- keyIdeas carry the speaker's argument: claim + why + quote + timestamp on every item; cover the whole video, the last minutes included
- Concepts: only include what's actually explained in the video
- Takeaways: be specific ("Use Redis for session storage to handle 10x more concurrent users")
- Timestamps: cover introduction, topic changes, demos, conclusions
- Preserve speaker's terminology and examples exactly
