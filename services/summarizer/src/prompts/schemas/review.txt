<domain_schema name="review">
REVIEW DATA — ReviewData schema

Extract a structured product review or comparison.

{
  "product": "Full product name with model number",
  "price": "Exact price with currency or null",
  "rating": {
    "score": 0.0,
    "maxScore": 10.0,
    "label": "Score label (e.g., 'Great', 'Average')",
    "quote": "The reviewer's words that give the score, verbatim, at most 25 words — no words, no rating",
    "timestamp": null
  },
> RATING: only a score the reviewer actually gives, with timestamp = the second they give it and quote = the words that give it; no stated score = leave the whole rating out. A score is never derived.
  "pros": [
    "Specific pro with real details: '5000mAh battery lasts 2 full days'"
  ],
  "cons": [
    "Specific con: 'No headphone jack — need USB-C adapter ($9)'"
  ],
  "specs": [
    {
      "key": "Display",
      "value": "6.7-inch AMOLED, 120Hz"
    }
  ],
  "comparisons": [
    {
      "feature": "Battery",
      "thisProduct": "5000mAh, 2-day battery life",
      "competitor": "4500mAh, 1.5-day battery life",
      "competitorName": "Competitor Product Name",
      "winner": "left | right | tie (which side wins this comparison, or null if no clear winner)"
    }
  ],
> UI: Comparisons → ComparisonInteractive table. Fill feature + thisProduct + competitor + competitorName for each row.
  "verdict": {
    "badge": "recommended | not_recommended | conditional | best_in_class",
    "bestFor": ["Specific use cases this product excels at"],
    "notFor": ["Specific use cases to avoid this product"],
    "bottomLine": "One-sentence verdict",
    "subScores": [
      {"category": "Camera", "score": null, "quote": null, "timestamp": null},
      {"category": "Battery", "score": null, "quote": null, "timestamp": null}
    ],
    "quote": "The reviewer's words that state the verdict, verbatim, at most 25 words — or null",
    "timestamp": null
  }
> VERDICT: timestamp = the second the reviewer states the verdict, quote = the words that state it — the badge is shown only with both; a badge the reviewer never states stays null. subScores only as the reviewer scores them, each with its timestamp and quote.
}

// Example for a phone review:
{
  "product": "Google Pixel 8 Pro", "price": "$999",
  "rating": {"score": 8.5, "maxScore": 10.0, "label": "Great", "quote": "Overall I'm giving the Pixel 8 Pro an eight and a half out of ten.", "timestamp": 612},
  "pros": ["Best camera in this price range — night mode is class-leading", "7 years of OS updates", "Tensor G3 chip enables on-device AI features"],
  "cons": ["Battery life is average — heavy users need a mid-day charge", "No headphone jack", "Runs warm during extended camera use"],
  "specs": [{"key": "Display", "value": "6.7-inch LTPO OLED, 120Hz"}, {"key": "Battery", "value": "5050mAh"}],
  "verdict": {"badge": "recommended", "bestFor": ["Photography enthusiasts", "Long-term Android users"], "notFor": ["Power users who need all-day battery", "Gamers"], "bottomLine": "The best camera phone under $1000, if you can live with average battery life.", "subScores": [{"category": "Camera", "score": 9.5, "quote": "The camera is a nine and a half, easily the best I've tested.", "timestamp": 301}, {"category": "Battery", "score": 7.0, "quote": "Battery gets a seven from me — fine, not great.", "timestamp": 455}], "quote": "If you care about photos, this is the one to buy.", "timestamp": 598}
}

RULES:
- Include all pros AND cons — never drop cons to soften the review
- All specs with actual numbers: "6.7-inch AMOLED, 120Hz" not "large display"
- Exact prices: "$999" not "premium price point"
- Exact ratings: "8.5/10" not "highly rated"
- Comparisons use real values: "5000mAh vs 4500mAh" not "bigger battery"
- Preserve the reviewer's verdict — if they say "skip it", don't soften
- Include model numbers and product names exactly
</domain_schema>
