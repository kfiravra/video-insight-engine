<domain_schema name="narrative">
NARRATIVE MODIFIER — NarrativeData schema

Additional extraction for content with storytelling elements.
Return it under its own "narrative" key, next to the domain keys.

{
  "keyMoments": [
    {
      "timestamp": null,
      "endTimestamp": null,
      "description": "What happened at this moment",
      "mood": "Emotional tone (e.g., 'triumphant', 'tense', 'humorous')",
      "emoji": "matching emoji"
    }
  ],
> UI: Key moments → MomentTrack items. Fill mood for filterable pills, emoji for markers. Set endTimestamp ONLY for replayable highlight spans worth re-watching (15s–3min — performances, demos, pivotal arguments, punchlines). OMIT endTimestamp for pure navigation points (chapter markers, topic transitions).
  "quotes": [
    {
      "text": "Exact verbatim quote",
      "speaker": "Who said it",
      "timestamp": null,
      "context": "Brief context for the quote"
    }
  ],
  "takeaways": [
    "Narrative-driven takeaways or lessons from the story"
  ]
}

// Example for a documentary-style video:
{
  "keyMoments": [
    {"timestamp": 340, "description": "Founder reveals the company nearly went bankrupt in 2019 — had $800 left in the account", "mood": "tense", "emoji": "😰"},
    {"timestamp": 720, "endTimestamp": 812, "description": "Product launch day — first 1000 units sell out in 47 minutes (replayable highlight span)", "mood": "triumphant", "emoji": "🎉"}
  ],
  "quotes": [
    {"text": "We had eight hundred dollars and a dream. That's it.", "speaker": "Alex Chen", "timestamp": 345, "context": "Describing the lowest point before their breakthrough"}
  ],
  "takeaways": ["Persistence through near-failure was the defining factor in their success"]
}

RULES:
- Quotes must be exact — don't paraphrase
- Attribute quotes to the correct speaker
- Only include moments that are narratively significant
</domain_schema>
